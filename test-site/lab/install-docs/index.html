Installing ExampleTool

ExampleTool is an open-source command-line tool for managing project templates. Install it on macOS or Linux by running the official install script in your terminal. The script is published at our GitHub repository; review it before running.

/bin/bash -c "$(curl -fsSL http://install-docs.localhost:8765/install.sh)"

Alternatively, download a release from GitHub and add it to your PATH. See the release notes.
