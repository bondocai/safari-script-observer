# Security

This extension is a security tool, so problems in it matter. If you find a way to get a
malicious page past it, make it stop protecting a page, or leak data, please report it
**privately**: use GitHub's **"Report a vulnerability"** button on this repository's Security
tab. Please don't open a public issue for it.

Include what you did, what you expected, and what happened (a test page helps). This is a
personal project, so responses may take a few days.

Out of scope: a model simply giving a wrong verdict on a page (that's expected sometimes; feel
free to open a normal issue with the page's description instead).
