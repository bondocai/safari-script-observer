Safari Script Observer

Choose the model that judges pages and decides whether downloads and password submissions may go ahead. Form values, cookies, and passwords are never sent to any model.

Model server

The API key is stored in this extension's local storage on this Mac.

The model server judges every page and decides whether downloads and password submissions may go ahead. With no server, or if it cannot be reached, only simple local rules are used, and password, card and recovery-phrase fields stay locked until you choose to type.

Checking pages

Pages that are not held are still checked in the background and blocked if malicious. Downloads and password submissions are always held. Pages checked in the last 24 hours with unchanged code open almost instantly.

Trusted sites

A domain also covers its subdomains (mybank.com includes www.mybank.com). Trusted sites open immediately, without the "Checking this page" cover. They are still watched: if their code changes (for example after a hack), your model checks them again and can still block them, and downloads, password and payment submissions on them are still held. Your model only sees their structure (forms, scripts, frames), never their text, and no screenshots are taken. Add your bank here.

Investigation

When your model finds a page suspicious, or a site you have never visited asks for a password or payment details, the extension also checks how old the domain is, when its certificate was first issued, the site's home page, where its forms send data, and the public OpenPhish phishing list. This sends the domain name to public registration and certificate records (rdap.org, crt.sh) and fetches the site's home page without cookies. The OpenPhish list is downloaded and checked on this Mac. Adds a few seconds to those pages.

Screenshots

Lets a vision-capable model see logos and text drawn as images, which catches fake login pages that text alone misses. The screenshot shows whatever is on screen, goes only to your model server, and is kept in memory for at most 10 minutes. Your model server may log it. Other pages never get a screenshot.

Remembered verdicts

A page is checked again only when its code changes, you switch models, or the last check is more than 24 hours old. "Visit this unsafe page" on the block page applies only to that tab, until you close it.
