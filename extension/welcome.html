Set up Safari Script Observer

Two things to finish, then it protects every page you visit. Page contents go only to the model server you choose.

The extension is on

You turned it on in Safari's settings.

Let it check every website

Checking…

It needs to see each page to protect it. Safari will ask once: choose Always Allow on Every Website.

No prompt? In Safari: Settings › Websites › Safari Script Observer, then set When visiting other websites to Allow.

Connect your model

Checking…

Optional: Private Browsing

Private windows aren't protected unless you allow it: Safari Settings › Extensions › Safari Script Observer › Allow in Private Browsing. The extension keeps a short local record of sites it checked, private ones included.

You're set. Pages open normally and are checked in the background; typing passwords, downloads and copied commands wait briefly while your model decides. The toolbar icon shows what it found.
